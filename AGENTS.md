# AGENTS — gestor-equipamentos

Workspace de memória persistente. Não é produto. Não criar `app/`, `specs/`, nem skill `harness-audit`.

## Antes de qualquer tarefa

1. Ler `harness/memory/active-context.md`.
2. Se a tarefa for ideia vaga ou “me questiona”, usar `grill-me`.
3. Se for salvar sessão / onde paramos / pausar, usar `session-handoff`.
4. Skill nova no harness só se o usuário pedir, via `harness-add-skill`.
