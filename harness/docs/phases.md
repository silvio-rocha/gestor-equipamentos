# Fases

## Fase 0 — Grill (agora)

Skill `grill-me` até veredito:

- **seguir** — ideia aguenta pressão; só então Fase 1
- **refinar** — volta ao grill (A e/ou B)
- **descartar** — registra o porquê; não avança

Sem código. Sem app. Sem specs.

## Fase 1 — Depois do veredito “seguir”

O usuário escolhe **um**:

- docs informal, ou
- SDD, ou
- build

Skills futuras da Fase 1 **não** implementar agora.
